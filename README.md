# 이음24 — 참여에서 채용까지

> 국민취업지원제도·청년도전지원사업에 참여한 청년의 이력을 **AI가 채용 언어로 바꿔** 공고와 잇고,

> 채용 후에는 **매월 급여 서류를 AI가 판독·점검**해 지원금 신청과 담당자 검토까지 이어지는 AI 고용서비스

## 팀 작업 규칙

- `main`에 직접 올리지 않습니다. 각자 브랜치(`seeker-data-이름`) → Pull Request, 합치기는 팀장이 합니다.
- 구직자 합성데이터는 **사람별 파일**에만 넣습니다: 지수 `data/synthetic/seekers_A.json`(P-A01~), 홍주 `seekers_B.json`(P-B01~). `seekers.json`은 수정하지 않습니다.
- 테스트 결과는 구직자 화면 [📥 내 서류함] → **[📤 테스트 결과 내보내기(JSON)]** 파일을 `results/`에 넣어 같은 PR로 올립니다 (개발 서버를 끄면 결과가 사라지므로 끄기 전에). 팀장은 [결과 불러오기(JSON)]로 여러 파일을 한 브라우저에 합칩니다. 방법: [results/README.md](results/README.md)
- PR 전 확인: `python3 tools/check_synthetic.py`(✖ 없음) · `python3 -m pytest -q tests`(모두 통과)
- API 키는 `.env`(내 컴퓨터)와 Vercel 환경 변수에만 둡니다.

## 사용자별 기능

| 사용자 | 화면 | 기능 | AI 활용 |
|---|---|---|---|
| 구직자 | `#seeker` | 참여 이력·경험 입력 → 활동 정리·역량 문장·포트폴리오 초안(**저장**), 맞춤 공고 추천, 동의 기반 배지, **[지원] → 그 회사 지원자 목록에 추가**, **내 서류함(근로계약서 서명·급여명세서 확인)** | 생성형 AI (문장 정리·추천 이유) |
| 기업 | `#employer` | **기업 선택(추후 기업 로그인)** → **공고 올리기**(점검·AI 정리·미리보기 → 게시) / **공고 확인**(구직자에게 보이는 모습·지원자 현황·채용 확정) → **표준근로계약서 자동 작성(법인 인장 날인·근로자 서명)** → **계약 조건대로 급여명세서 발급·이체확인증 대조**, (선택) 사업자등록증·외부 양식 서류 판독 | 생성형 AI (공고 정리), **멀티모달 AI (이체확인증·서류 이미지 판독)** |
| 담당자 | `#officer` | 저장된 신청 건에서 참여 이력 근거·지침 조항·계약 점검·**서명된 근로계약서·월별 명세서 대조 기록**을 바로 확인 — 서류를 다시 요구하지 않음 (자동 판정 없음) | 규칙엔진 결과 요약 |

### 시연 흐름 (로그인 없이 저장)

1. 구직자 화면: 이름(가명)·이력 입력 → [AI로 이력 정리 · 공고 추천] → 포트폴리오 저장 → 추천 공고 [이 공고에 지원]
2. 기업 화면: 지원한 회사 선택(또는 **[+ 우리 회사 등록]으로 신규 기업 가입** — 회사 정보·가상 법인 인장 저장) → [공고 확인 · 지원자]에서 내 지원서 확인 → [채용 확정]
3. 근로계약서: 저장된 구직자 정보 + 공고 조건으로 고용노동부 표준근로계약서가 채워짐 → 사업주 날인은 회사별 가상 법인 인장(`data/synthetic/seals/`) 자동 → 근로자 서명란 버튼으로 직접 서명 또는 인장 이미지 → 저장하면 규칙 점검·담당자 신청 건 생성
4. 급여명세서: **근로자 서명 뒤, 지급일이 지난 달만 매월** 계약 조건(월급·수당·지급일)으로 발급(월 중간 입사·종료 달은 일할 계산, 계약 변경 시 기존 명세서는 정정(취소) 이력으로 보관) → 근로자 [내 서류함]으로 전송 → 달마다 **이체확인증 첨부**(가상 은행 양식 예시 4종: 정상 / 금액 다름 / 이체자 다름 / 받는 분 다름, 또는 내 파일) → AI가 **이체금액·보내는 분(이체자)·받는 분(예금주)·이체일**을 읽어 명세서·계약과 비교표로 대조. 6개월 흐름은 [기존 근로자 등록]으로 시연
5. 담당자 화면: 신청 건에서 계약서·명세서 열람 → 보완 요청 / 검토 완료(저장)

구직자 화면의 [내 서류함]에서 저장된 구직자로 바꾸거나 새 구직자로 작성할 수 있고, 기업 선택 화면에 **저장 현황**(구직자·기업·공고·지원·계약서·명세서 건수)과 **[저장 데이터 내보내기(JSON)]**가 있습니다.

저장 방식: GitHub는 코드 저장소라 배포된 서비스가 실행 중에 데이터를 써 넣지 않습니다. Vercel 프로젝트에 **Upstash Redis**를 연결하면(KV_REST_API_URL·KV_REST_API_TOKEN 자동 입력) 서버에 저장되어 다른 기기에서도 같은 시연 데이터가 보입니다. 연결하지 않으면 **각 브라우저(localStorage)**에 저장되므로 같은 브라우저에서 세 화면을 오가며 시연합니다. 서버 저장은 마지막 저장 후 30일 뒤 자동 삭제되며, 기업 선택 화면의 [시연 데이터 초기화]로 바로 지울 수 있습니다. 합성 데이터만 입력하세요.

## 기술 스택

- **AI**: 배포는 Anthropic Claude Haiku 4 (교육용 게이트웨이). 코드는 Anthropic · OpenAI · Gemini API 중 하나를 지원 — 교육용 게이트웨이(중계 주소) 사용 가능, `AI_MODEL`로 모델 변경
- **Backend**: Python 표준 라이브러리만 사용한 Vercel Serverless Functions (`api/*.py`)
- **Frontend**: HTML, CSS, Vanilla JavaScript (빌드 도구 없음)
- **Data**: 고용24 OpenAPI 채용정보(키가 없으면 합성 공고), 2026년 청년일자리도약장려금 사업운영 지침(규칙DB), 고용노동부 표준근로계약서 양식
- **Storage**: Upstash Redis REST (선택, 무료 등급으로 충분) — 미연결 시 브라우저 localStorage
- **Infra**: Vercel (GitHub push → 자동 배포)

선정 이유: 외부 패키지가 없어 팀원 누구나 `python dev_server.py` 한 줄로 실행할 수 있고, 배포가 단순합니다.

## 핵심 AI 활용 — 판단은 규칙엔진, AI는 번역과 설명

과제 필수 기술 요소: **멀티모달 AI**(서류 이미지·PDF 판독) + **자동화 워크플로우**(채용 확정 → 계약서 자동 작성 → 매월 명세서 → 이체 대조 → 담당자 신청 건 자동 생성)

1. **생성형 AI**: 서술형 참여 이력 → 직무 역량 문장·포트폴리오 초안, 공고 정리, 점검 결과 설명
2. **멀티모달 AI**: 근로계약서·사업자등록증·급여명세서·이체확인증 이미지에서 정해진 항목만 추출 → 규칙엔진이 점검하고 공고 입력값·공공데이터와 대조 (방식: docs/ai-document-reading.md)
3. **할루시네이션 방지 (guard)**: 입력에 없는 숫자·지원금·연령이 들어간 AI 문장, 후보 목록에 없는 공고 ID는 서버에서 차단
4. **차별 방지**: 배지 사유·연령은 기업에 보이지 않고, 배지 기준 정렬·필터를 제공하지 않음
5. **사람이 최종 결정**: 포트폴리오 초안의 원문에 없는 말·과장 표현은 색으로 표시하고 본인 확인 후 저장, 애매한 서류 판독은 '확인 필요'로 담당자에게
6. **AI 윤리**: AI가 만든 내용은 화면에 "AI가 정리" 등으로 표시, AI 처리 동의 없이는 AI 서버로 보내지 않음

## 실행 방법

```bash
git clone <이 저장소 주소>
cd <저장소 폴더>
cp .env.example .env      # AI 키를 넣으면 AI 기능 동작, 비우면 규칙 기반 기본 문장으로 동작
python3 dev_server.py     # → http://127.0.0.1:3000
python3 -m pytest -q tests
IEUM_E2E=1 python3 -m pytest -q tests/e2e   # 화면 전체 흐름 자동 테스트 (Playwright 필요, 약 2분)
python3 tools/eval_mvp.py # 사전 검증 지표 재측정
python3 tools/check_synthetic.py # data/synthetic 합성데이터 자가 점검 (docs/data-spec.md)
python3 tools/make_seals.py      # 회사별 시연용 가상 법인 인장 PNG 다시 만들기 (Pillow 필요)
```

키 값은 `.env`(로컬)와 Vercel 환경 변수에만 넣고, 코드·채팅·스크린샷에 올리지 않습니다.
