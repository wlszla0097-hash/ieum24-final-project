# 상황별 시연·테스트 시나리오 (합성데이터 기준표)

규칙이 바뀌어도(채용일 기준 판정·군필 연동·최저임금 차단 등) 같은 데이터로 같은 결과가 나오는지 확인하는 표입니다.
모든 인물·기업·공고는 합성(가상) 데이터입니다. 실측은 배포 주소(claude-haiku-4) 기준입니다.

## 0. 평가 당일 정상 시연 경로 (고정)

같은 브라우저에서, 아래 순서 그대로 진행합니다. 신규 기업 등록은 별도의 짧은 시연으로 분리합니다.

1. 구직자: **윤하람 P-S04** 또는 **송민재 P-S05** 예시 불러오기 → 동의 3개 체크 → AI 정리·추천
2. '지원제도 활용 가능' 표시가 붙은 **기존 합성 기업** 공고에 지원 (새로 등록한 기업은 등록 전 달 명세서가 막혀 6개월 시연에 쓰지 않음)
3. 기업 화면 → 채용 확정 → [기존 근로자 등록] → 서명 → 저장
4. 급여 → 일괄 발급·대조 (6/6개월, 불일치 1·확인 필요 1이 의도된 결과)
5. 담당자 화면 → 근거·6개월 경과·담당자 확인 항목 확인 → 처리
- 증빙 서류 예시([시연: 예시 서류 넣기])는 지금 입력된 사람의 이름·날짜로 만들어집니다. 실제 파일을 올릴 때 암호 PDF·확장자만 바꾼 파일은 이유를 안내하고 판독하지 않습니다(이미지로 캡처해 올리면 됨).
- AI가 느리거나 실패하면: 해당 달은 '확인 필요(미판독)'로 남고 진행됩니다. 대비용 화면 녹화를 준비하고, 사용 시 '대체 시연'이라고 밝힙니다.

결과 표기 원칙: 숫자는 "합성 사례 ○건에서 기대 결과와 일치"로 씁니다. 실제 현장 정확도를 뜻하지 않습니다.
