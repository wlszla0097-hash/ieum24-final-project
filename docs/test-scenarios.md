모든 인물·기업·공고는 합성(가상) 데이터입니다. 실측은 배포 주소(claude-haiku-4) 기준입니다.

### 구직자 직접 작성 → 채용까지 (화면 실측)

| 단계 | 결과 |

| 맞춤 포트폴리오 | 1,514자 · 15.4초 · 원문에 없는 숫자 차단 0건 · 사업명은 '직무 훈련 과정'으로 가림 |
| 저장 → 새로고침 | 그대로 남아 있음, [저장된 이력 불러오기]로 입력 칸 복원 |
| 다시 추천 (14.5초) | 바른정밀 공고가 '지원제도 활용 가능' 배지와 함께 나옴 |
| 지원 → 기업 화면 | 지원자 목록에 하윤서 + 포트폴리오 요점 |
| 채용 확정 | 표준근로계약서 자동 채움 → 위반 0건 저장, '체결 완료' (환산 시급 13,876원) |
| 급여명세서 | 오늘 입사라 모든 달 '발급 예정' (매월 발급 원칙) |
| 담당자 화면 | '취업애로청년 근거: 청년도전지원사업 수료(2026-06-30)', 입사 2026-10-17 |

> 화면에서 만든 데이터는 그 브라우저에만 저장됩니다. 다른 컴퓨터로 옮기려면 [저장 데이터 내보내기] → JSON → `results/` 폴더 PR → [결과 불러오기].
