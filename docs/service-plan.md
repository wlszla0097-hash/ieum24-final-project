# 서비스 기획서 — 이음24

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | 이음24 — 참여에서 채용까지 |
| 한 줄 소개 | 국민취업지원제도·청년도전지원사업 참여 이력을 AI가 채용 언어로 바꿔 공고와 잇고, 기업에는 본인 동의 하에 '지원제도 활용 가능' 표시를 보여 주며, 채용 확정 시 근로계약 점검·신청 알림까지 잇는 고용서비스 |
| 해결 문제 | ① 고용서비스 참여·수료가 채용으로 이어지지 않는 단절 ② 청년도 기업도 모르는 채용지원금 연계 ③ 채용 6개월 뒤 신청 단계에서야 요건을 확인해 생기는 보완·반려 |
| 배경 | 기획자는 중소기업 고용지원금 신청과 근로계약 검토 실무를 하며, 참여 이력이 수료증으로만 남고 채용·지원금으로 이어지지 않는 사례를 반복해서 봤다. |
| 근거 지침 | 2026년 청년일자리도약장려금 사업운영 지침 1-3항: 수도권 기업 유형의 '취업애로청년'에 국민취업지원제도 참여 후 최초 취업 청년, 청년도전지원사업 수료 청년이 포함됨. 비수도권 기업 유형은 취업애로 요건 없음 |

## 2. 타겟 사용자

| 사용자 | 상황 | 얻는 가치 |
|---|---|---|
| 국취·청년도전 참여 청년 (주 이용자) | 프로그램 수료 직후, 취업활동계획에 따라 구직 중 | 참여 이력 → 직무 역량 문장·자기소개 초안, 맞춤 공고, 동의 기반 표시로 서류 단계 차별화 |
| 청년 채용을 계획하는 중소기업 인사담당자 | 공고를 올리고 지원자를 검토·채용 | 공고별 지원제도 연계 점검, 면접 전 표시 확인, 근로계약 점검, 신청 시기 알림 |
| 고용센터·운영기관 담당자 | 장려금 신청 접수·검토 | 참여 이력 근거·지침 조항·계약 점검이 정리된 신청 건 (최종 결정은 담당자) |

## 3. 페이지 구성 (해시 메뉴 이동, 상단 메뉴 + 모바일 햄버거 메뉴)

| # | 섹션 | 주소 | 내용 |
|---|---|---|---|
| 1 | 홈 | `#home` | 참여→채용 흐름(구직자·기업·담당자 ①~⑦), 세 가지 단절, 설계 원칙 |
| 2 | 구직자 | `#seeker` | 참여 고용서비스(선택·날짜) + 내 경험(자유 서술) + 희망 직무·지역 직접 입력 → 표시 동의 → AI 이력 정리·역량 문장·추천 공고·지원 (예시 불러오기 제공) |
| 3 | 기업 | `#employer` | 공고 조건·본문 직접 입력 → 규칙 점검 + AI 공고 정리 + 지원자 목록 → 채용 확정 → 근로계약 점검·신청 알림·신청 근거 |
| 4 | 담당자 확인 대시보드 | `#officer` | 신청 건 카드(근거·확인 항목·신청 시기·처리 버튼) |
| 5 | 안내 | `#about` | 동작 방식, FAQ, 데이터 출처, 연동 상태 |

반응형 기준: 900px 이하 입력·결과 세로 배치, 720px 이하 햄버거 메뉴·1열 입력칸. 다크 모드 제공.

## 4. 핵심 기능

### 기능 ① 수료 후 취업 연계 (`POST /api/seeker`) — AI
| 구분 | 내용 |
|---|---|
| 입력 | 참여한 고용서비스(국취: 수급자격 인정일·취업활동계획 수립·참여 후 취업 여부 / 청년도전: 수료일), 청년 여부(나이 숫자는 받지 않음), 내 경험(자유 서술 1,500자, 필수), 희망 직무(필수)·지역, 동의(필수 수집·이용 / AI 처리 / 선택 표시 공개·채용 후 세부정보·증빙 판독) |
| 처리 | ① 코드가 공고 후보 선정(경험 속 기술·희망 직무 일치, 지역 가점, 임금체불 명단공개·마감 공고 제외) → ② AI가 자유 서술을 활동별(구분·활동·기간)로 정리하고 역량 문장·자기소개 초안·후보 공고 추천 이유 작성 → ③ 서버 가드: 후보 외 id 제거, 지원금·연령 언급·입력에 없는 숫자 문장 차단 → ④ 규칙엔진이 공고별 표시 여부 판단 |
| 출력 | AI가 정리한 이력 표, 역량 문장(근거 활동 표시), 자기소개 초안, 추천 공고(일치 기술 태그, 추천 이유, 준비할 것, 나에게만 보이는 표시 안내와 지침 근거) |

### 기능 ①-2 증빙 서류 판독 (`POST /api/certificate`) — AI (이미지·PDF 입력)
| 구분 | 내용 |
|---|---|
| 입력 | 수료증·참여확인서 이미지(PNG·JPG·WEBP) 또는 PDF, 3MB 이하, '증빙 서류 AI 판독' 동의 필수 |
| 처리 | AI는 사업명·과정명·발급기관·날짜만 읽음(성명·생년월일 출력 금지, 서버도 정해진 항목만 반환) → 폼에 채움 → 본인 확인·수정 → 판단은 규칙엔진이 폼 값으로 |
| 출력 | 판독 결과 카드, 입력칸 자동 채움, 신청 건에 "AI 판독 날짜가 입력값과 일치/다름" 증빙 표시 |

### 기능 ①-3 포트폴리오 (`POST /api/seeker` action=portfolio) — AI 1회
| 구분 | 내용 |
|---|---|
| 처리 | 정리된 활동과 원문으로 AI 초안 1회 생성(참여 사업명·없는 성과 금지, 원문에 없는 숫자 차단) → 본인 편집 → 등록 |
| 기업 화면 | 지원자가 등록한 **핵심 포인트**를 먼저, 전체는 펼쳐 보기. 기업 쪽은 AI 재호출 없음(토큰 0). 채용 전에는 참여 사업명이 들어간 문장을 제외 |

### 기능 ② 공고 점검 · 지원자 확인 (`POST /api/employer`) — 규칙 + AI 정리
| 구분 | 내용 |
|---|---|
| 입력 | 회사명(가명 가능), 근무지 시·도(필수)·시군구, 공고 제목·직무·고용형태·월 임금(필수), 주 소정근로시간, 피보험자 수, 우선지원대상기업 여부(예/아니오/모름), 공고 본문 |
| 처리 | 규칙: 소재지(수도권/비수도권 유형), 정규직, 우선지원대상기업, 피보험자 5인 이상, 최저임금 환산, 연령·성별 제한 표현(고용상 연령차별금지법·남녀고용평등법) 점검 → "연계 가능성 높음/확인 필요/연계 어려움". AI: 공고 요약·요구 역량·보완 제안 (요구 역량은 본문에 실제 있는 단어만 남김) |
| 지원자 | 지원일 순 고정. 응답에는 표시 여부(true/false)만 포함, 사유·연령·참여 이력 미포함. 비수도권 공고는 지원자별 표시 없이 공고 단위 안내 |

### 기능 ③ 채용 확정 → 근로계약 점검 · 신청 알림 (`POST /api/check`, `POST /api/cases`) — 규칙 + AI 설명
| 구분 | 내용 |
|---|---|
| 처리 | 공고 내용으로 근로조건 자동 채움 → 규칙 엔진이 최저임금·근로시간·휴게·필수 기재사항·계약기간 판정 → AI는 판정 결과만 쉬운 말로 설명 → 6개월 고용유지 시점·알림일 계산 → 동의한 경우에만 참여 이력 근거를 신청 건에 첨부 |

### 기능 ④ 담당자 확인 대시보드 (`GET /api/cases`)
신청 건마다 참여 이력 근거(동의 시), 지침 조항, 기업 요건·계약 점검·고용유지 확인 항목, 신청 시기를 모아 보여 준다. 상태(검토 대기/확인 필요/보완 필요)는 확인 항목 집계일 뿐 판정이 아니며, 처리 버튼은 담당자가 누른다.

## 5. AI 기능의 입력·출력·실패 처리 기준

### 입력 기준
- 필수값: 구직자(내 경험 10자 이상·희망 직무, 체크한 사업의 날짜, 필수 동의), 기업(근무지·제목·직무·고용형태·월 임금), 채용 확정(입사일·기본급·주 소정근로시간). 프론트와 서버 모두 검사.
- 길이 제한: 내 경험 1,500자, 공고 본문 1,500자, 포트폴리오 4,000자, 증빙 파일 3MB. 미래 날짜는 거부. 성명·연락처·주민번호 입력 금지 안내.
- 동의: 필수 동의가 없으면 서버가 처리 거부, AI 처리 동의가 없으면 AI 서버로 보내지 않고 규칙 결과만.

### 출력 기준 (할루시네이션·차별 방지)
- AI 응답은 정해진 JSON만 허용, 해석 실패 시 규칙 기반 기본 결과로 대체.
- 추천 공고 id는 서버가 넘긴 후보 안에서만 허용, 공고명·기업·링크는 원본 데이터로 표시.
- AI 문장에 지원금·장려금·수급·자격 요건·연령 언급이나 입력에 없던 숫자가 있으면 차단하고 개수를 표시.
- 표시 판단은 규칙엔진만 하며 AI 프롬프트에 연령을 넘기지 않음.
- 모든 결과에 "예상 안내, 최종 확인은 고용센터" 문구 표시.

### 실패 처리 기준

| 상황 | 기준 | 안내 |
|---|---|---|
| 빈 입력 | 필수값 누락 | "필수값을 입력하세요: (항목)" + 입력칸 강조 |
| AI 키 미설정 | 환경 변수 없음 | 규칙 기반 기본 문장으로 표시하고 안내 |
| API 오류 | AI 4xx/5xx | 오류 안내(오류 코드), 규칙 결과는 유지 |
| 지연 / 타임아웃 | 8초 / 서버 25초·브라우저 45초 | "늦어지고 있어요" / "응답 시간이 초과되었습니다" |
| 과다 요청 | IP당 1분 10회 | 429 안내 |
| 데이터 실패 | 고용24·공공데이터 | 합성 공고·예시 데이터로 전환, 출처 표시 |
| 동의 누락 | 필수·판독 동의 없음 | "[필수] 개인정보 수집·이용에 동의해 주세요" 등, 서버도 거부 |
| 파일 오류 | 형식·용량·판독 실패 | "3MB 이하로 올려 주세요" / "직접 입력해 주세요" |

### 테스트 입력/결과 예시 (tests/ 41개 자동 테스트 + 배포 사이트 실제 AI 검증)

| 구분 | 입력 | 기대 결과 |
|---|---|---|
| 표시 대상 | 김하늘(국취, 참여 후 취업 없음) + 서울 정규직 공고 | ‘지원제도 활용 가능’ 표시 |
| 최초 취업 아님 | 박지민(국취 참여 중 고용보험 취득) + 인천 공고 | 표시 없음 |
| 일반 훈련만 | 최유나 + 서울 공고 | 표시 없음 |
| 비수도권 | 이서준 + 부산 공고 | 지원자 표시 없이 공고 단위 안내 |
| 대기업 공고 | 우선지원대상 아님 | 표시 없음 |
| 동의 안 함 | 대상자지만 미동의 | 기업 화면 표시 없음, 신청 건 근거 비공개 |
| AI 가드 | "지원금을 받을 수 있습니다", "3년 경력" | 차단 |
| 계약 점검 | 기간제·월 200만원·1일 9시간·휴게 30분 | 최저임금·근로시간·휴게·계약기간 위반 의심 |
| 빈 입력 | 내 경험·희망 직무 비움 | "필수값을 입력하세요: 내 경험, 희망 직무" |
| 긴 입력 | 내 경험 1,500자 | 정상 처리(초과 입력 불가), 8초 넘으면 지연 안내 |
| 수료증 판독 | 가상 수료증 이미지 (청년도전, 2026-07-31) | 사업·날짜 정확히 판독, 성명·생년월일 미출력 (실측 약 4초) |
| 차별 표현 | 공고 본문 "30세 이하, 남성 우대" | '채용 차별 소지 표현' 확인 필요 |
| 정보 가림 | 포인트에 "청년도전지원사업 수료" | 채용 전 기업 화면에서 제외 |

## 6. 검증 지표 (합성데이터 기준)
- 표시 판정 일치율(지침 정답 대비), 근로계약 의도적 오류 탐지율
- AI 문장 내 근거 없는 요건·수치 / 기업 화면 사유·연령 노출: 0건
- 추천 공고 중 실제 목록 외 항목: 0건

## 7. 비용·운영 고려
- 빠르고 저렴한 모델(Haiku/Flash) 기본, 응답 길이 제한, 공고는 코드가 먼저 5건으로 좁힌 뒤 AI 호출.
- AI가 없어도 핵심 흐름이 동작하므로 AI 장애가 서비스 중단으로 이어지지 않음.
