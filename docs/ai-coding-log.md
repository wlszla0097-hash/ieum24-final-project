# AI 코딩 도구 사용 기록 — 오류 원인 파악과 수정

AI 코딩 도구(Claude)와 대화하며 기획 → 구현 → 배포 → 실사이트 테스트를 반복했습니다.
아래는 그중 **배포·운영 중 실제로 겪은 문제**와, 원인을 어떻게 찾고 고쳤는지 정리한 것입니다. (커밋 이력과 함께 확인할 수 있습니다)

| # | 증상 | 원인 파악 방법 | 원인 | 수정 |
|---|---|---|---|---|
| 1 | Vercel 첫 배포에서 빌드 실패 | Vercel 빌드 로그 확인 | `api/` 안에 함수가 아닌 공용 파일(`_ai.py` 등)이 섞여 있어 함수로 인식 | 공용 모듈을 `core/`로 분리하고 `vercel.json`의 `includeFiles`로 함께 묶음 |
| 2 | "No python entrypoint found" | 오류 문구 검색, `requirements.txt` 존재 여부 확인 | `requirements.txt`가 있으면 Vercel이 프로젝트 전체를 Python 단일 앱으로 판단 | `vercel.json`에 `"framework": null` 지정 → 파일별 함수로 동작 |
| 3 | `/api/case`만 배포 사이트에서 응답 없음 (로컬은 정상) | 임시 진단 코드를 넣어 재배포 → 그래도 실패 → 모듈 로딩 단계 문제로 범위 축소 | 함수 파일 이름 `case`가 Vercel 실행 환경에서 문제를 일으킨 것으로 추정 (Python의 `case` 예약어 계열) | `api/cases.py`로 이름 변경 후 정상, 진단 코드 제거 |
| 4 | AI 키를 넣었는데 "AI 서비스 인증 실패(401)" | `/api/health`에 키 **형식**(값 제외)만 보여 주는 진단 항목 추가 | 교육용 키는 Anthropic 공식 키가 아니라 **교육용 중계 서버 전용 키** | `ANTHROPIC_BASE_URL`(중계 서버 주소)·`AI_MODEL` 환경 변수 추가, 주소 끝 `/v1` 자동 정리, 키 앞뒤 공백 자동 제거 |
| 5 | 근로계약 AI 설명에 "월 2,150,000원 이상으로 인상" (실제 기준 2,156,880원) | 실사이트 결과를 규칙 계산값과 대조 | AI가 점검 결과에 없는 숫자를 만들어 냄 (할루시네이션) | 근로계약 설명에도 숫자 검증 가드 적용, 규칙 결과에 "월 환산 최소 금액"을 직접 표시 |
| 6 | 이력 정리에서 가장 중요한 '데이터 분석 과정 수료'가 빠짐 | 입력 원문과 결과 비교, 차단 건수 확인 | AI가 날짜를 '2026.08'로 바꿔 쓰자 숫자 검증이 새 숫자로 오인 | 숫자를 정수 단위로 비교하도록 가드 개선, 회귀 테스트 추가 |
| 7 | 기업 화면에 "[참여 사업 비공개] 장기 프로그램 수료" | 기업 응답 JSON 검사 | 가려도 참여 사실이 짐작됨 (차별 방지 원칙 위반) | 채용 전 기업 화면에서는 해당 문장을 통째로 제외, 테스트 추가 |
| 8 | 내 도구로 배포 사이트 테스트가 계속 '예전 결과' | 같은 주소를 브라우저로 직접 열어 비교 | 웹 읽기 도구의 캐시 | 데스크톱 앱 브라우저 패널에서 실제 요청(fetch)을 보내 검증하는 방식으로 변경 |
| 9 | 모바일(375px)에서 추천 공고 카드가 오른쪽으로 잘림 | 배포 사이트를 375px로 열고 화면보다 넓은 요소를 스크립트로 찾음 → 페이지 폭 457px | 예시 선택 상자(긴 옵션 글자)와 fieldset의 최소 너비가 칸을 밀어냄 | 선택 상자·fieldset 최소 너비 0, 긴 글자 줄바꿈 → 7개 화면 모두 375px 확인 |

## 배운 점
- **로컬에서 되는데 배포에서 안 되면** 실행 환경 차이(빌드 방식, 파일 이름, 환경 변수)를 먼저 의심하고, 진단용 정보를 안전하게(키 값 제외) 노출해 범위를 좁힌다.
- **AI 결과는 반드시 원문·규칙 결과와 대조**한다. 그럴듯하지만 틀린 숫자가 실제로 나왔고, 서버 검증 가드로 막았다.
- **키는 환경 변수로만** 관리하고, 바꾼 뒤에는 재배포해야 반영된다. 키 화면은 캡처·채팅에 올리지 않는다.
