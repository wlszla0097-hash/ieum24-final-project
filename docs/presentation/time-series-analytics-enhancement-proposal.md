# 시계열 분석 고도화 수정 제안서

- 대상: [이음24 발표자료](이음24_발표자료.pdf) 마지막 장의 「② 시계열 분석」
- 수정 방향: 기존 카드 문구 보강 + 핵심 아키텍처와 에이전트 역할을 설명하는 장표 1장 추가
- 제안 범위: 배포 이후 추진할 고도화 구상

## 1. 고도화 목적

- 현재 이음24는 급여명세서와 이체확인증을 대조해 해당 월의 지급 내역을 점검
- 다음 단계에서는 월별 기록을 함께 살펴보고, 변화와 누락을 확인하는 방향으로 확장
  - **고용유지 이상 신호:** 지급 지연·금액 변화·서류 누락 등 확인이 필요한 흐름 파악
  - **신청 시기 안내:** 입사일·고용기간·제도 기준으로 신청 가능 시점과 준비할 서류 안내
  - **채용공고 추이:** 지역·직무별 공고 수와 증감 추이를 분석해 채용 수요의 변화 확인
- 개별 서류를 점검하는 기능에서, 쌓인 기록으로 다음 업무를 준비하도록 돕는 기능으로 발전

## 2. 분석 플랫폼: Firestore + BigQuery

| 도구 | 담당 역할 | 활용할 데이터 |
|---|---|---|
| **Firestore** | 사용자별 업무 기록과 진행 상태 저장 | 계약·급여·이체 대조 결과·신청 상태 |
| **BigQuery** | 기간별 기록을 모아 집계·비교 | 월별 지급 이력, 지역·직무별 채용공고 이력 |

- 마지막 장에 제안된 Firestore 도입 계획과 연결해, 분석에 필요한 기록을 BigQuery로 정기 적재
- 초·분 단위 실시간 처리보다 월별 기록 비교와 정기 분석이 중심이므로 BigQuery를 우선 선택
- 급여·이체 이력과 외부 채용공고를 SQL로 집계하고, 향후 BigQuery ML을 활용한 예측으로 확장
- 장표에는 전용 시계열 DB 대신 **‘시계열 분석 플랫폼: BigQuery’**로 표기

## 3. 핵심 아키텍처와 에이전트 구성

```text
Firestore 업무 기록          고용24 채용공고
          └────── 정기 수집·정제 ──────┘
                         ↓
                      BigQuery
                         ↓
              데이터 분석 에이전트
                변화·이상 신호·근거
                         ↓
               업무 지원 에이전트 ← 제도 기준·일정 계산 도구
                         ↓
               분석·안내 결과를 Firestore에 저장
                         ↓
                기업·담당자 화면 및 알림
```

### 두 에이전트의 역할

| 에이전트 | 수행할 작업 | 제공할 결과 |
|---|---|---|
| **데이터 분석 에이전트** | BigQuery 조회·Python 분석 도구로 급여·이체 이력과 채용공고 분석 | 지급 지연·금액 변화·기록 누락, 지역·직무별 공고 증감과 근거 |
| **업무 지원 에이전트** | 분석 결과에 계약·신청 상태와 제도 기준을 연결하고 일정 계산 도구 활용 | 신청 가능 시점, 준비 서류, 기업·담당자가 확인할 항목 |

### 구현 구상

- **LangGraph**로 데이터 분석 → 업무 지원 → 결과 저장 흐름 구성
- 각 에이전트는 필요한 조회·분석·일정 계산 도구를 호출하고, 반환된 결과를 정리해 다음 단계로 전달
- 수치 집계와 날짜 계산은 SQL·Python·규칙 도구가 수행하고, AI는 도구 선택과 결과 설명을 담당
- 고용유지·신청 시기·채용 추이를 별도 에이전트로 나누지 않고, 두 에이전트가 활용하는 도구로 구성
- 새로운 분석이 필요하면 해당 도구를 추가하는 방식으로 확장

## 4. 단계별 추진 방향

| 단계 | 추진할 내용 |
|---|---|
| **기록 축적** | Firestore 업무 저장 도입과 함께 월별 지급·대조 기록 보관, 고용24 공고 정기 수집, BigQuery 적재 |
| **기초 분석 제공** | 규칙 기반 이상 신호 점검, 신청 가능일 계산, 지역·직무별 공고 증감 분석과 업무 안내 |
| **예측 기능 확장** | 이력과 표본이 충분히 쌓인 뒤 BigQuery ML 기반 이상 탐지·채용공고 추이 예측을 검증하고 적용 |

- 급여·이체 기록의 이상은 **확인이 필요한 신호**로 안내하고, 재직 여부를 확정하는 근거로 사용하지 않음
- 신청 가능일은 **제도 기준에 따른 계산**으로 제공하고, 미래 추이를 추정하는 예측 기능과 구분
- 고용24 데이터로 제공하는 통계는 실제 채용 실적이 아닌 **채용공고 추이**로 명시

## 5. 장표 반영안

### 기존 마지막 장: 「② 시계열 분석」 카드 교체

**② 시계열 분석 · 업무 지원**

> Firestore 기록을 BigQuery로 분석해 고용유지 이상 신호·신청 가능 시점·지역·직무별 채용공고 추이를 안내. 데이터 분석·업무 지원 에이전트로 역할 분담

### 추가 장표: 데이터에서 업무 안내로 이어지는 흐름

- **제목:** 쌓인 기록을 분석하고, 다음 업무를 안내한다
- **배치:** 마지막 장 다음에 1장 추가
- **중앙:** 3절의 아키텍처 도식 배치
- **역할 설명:** 도식의 두 에이전트 옆에 각각 한 줄로 표시
  - **데이터 분석:** 급여·이체 기록의 이상 신호와 채용공고 추이 분석
  - **업무 지원:** 신청 가능 시점·준비 서류·확인 항목 안내
- **하단:** ‘기록 축적 → 기초 분석·업무 안내 → 예측 기능 확장’ 순서 표시
- **핵심 문구:** 데이터 분석 에이전트가 변화를 발견하고, 업무 지원 에이전트가 다음 행동을 안내합니다.
