# 시연·테스트 방법 (최신)

배포 주소: https://ieum24-final-project.vercel.app
모든 이름·회사·사업자번호·서류는 **가상(합성) 데이터**만 씁니다. 실제 이름·연락처·주민번호·계좌번호는 넣지 마세요.

## 0. 먼저 알아 둘 것 — 저장 방식

- 로그인 없이 시연하려고 입력한 내용을 저장합니다.
- 지금은 **각자의 브라우저에만 저장**됩니다. 같은 브라우저에서는 새로고침해도 남아 있지만, 다른 기기·다른 팀원 화면에는 보이지 않습니다.
- 그래서 **한 브라우저에서 구직자 → 기업 → 담당자 화면을 차례로** 오가며 테스트합니다.
- (서버 저장소가 연결되면 이 안내가 바뀝니다. [안내] 화면 아래 '시연 데이터 저장' 표시로 확인)
- 처음 열었을 때 화면이 예전 모습이면 새로고침(Ctrl+F5) 한 번.
- AI 키가 없을 때는 AI 대신 기본 문장으로 동작합니다. 흐름 테스트에는 문제없습니다.

## 1. 구직자 — 이력 저장 · 지원

1. 상단 [구직자] → [예시 불러오기]에서 아무 예시나 고르기 (또는 직접 입력)
2. 맨 위 **이름(가명)** 입력 (예: 정다온)
3. 4번 동의 항목에서 [필수] 개인정보 동의 체크 → [AI로 이력 정리 · 공고 추천]
4. 오른쪽 아래 포트폴리오에 내용을 쓰고 [포트폴리오 저장]
5. 추천 공고 중 하나에서 [이 공고에 지원] → 버튼이 '지원 완료 ✓'로 바뀜
6. 화면 맨 위 **📥 내 서류함**에 지원 현황이 생김
   - [+ 새 구직자로 작성]으로 두 번째 구직자를 만들 수 있고, [저장된 구직자로 바꾸기]로 오갈 수 있음

## 2. 기업 — 회사 선택 또는 신규 등록 · 공고

1. 상단 [기업] → 기업 목록 (실제 서비스에서는 기업 로그인 자리)
   - 맨 위 **저장 현황**에 지금까지 쌓인 구직자·기업·공고·지원 건수가 보임
2. 둘 중 하나
   - 1단계에서 지원한 회사 카드를 클릭 (카드에 '지원자 n명' 표시)
   - **[+ 우리 회사 등록]** → 회사명, 사업자등록번호(**000으로 시작하는 10자리**, 예: 000-12-34567), 업종, 소재지, 피보험자 수 입력 → 등록하면 가상 법인 인장이 만들어짐
3. **[📝 공고 올리기]**: 제목·직무·월 임금·본문 입력 → 오른쪽 '구직자에게 보일 모습' 확인 → [공고 점검 · AI 정리] → [이 공고 게시하기]
   - 게시한 공고는 구직자 추천 후보에 들어감 (1단계를 다시 하면 추천에 뜨는지 확인 가능)
4. **[📋 공고 확인 · 지원자]**: 공고를 고르면 구직자에게 보이는 모습, 지원제도 점검, 지원자 현황이 나옴
   - 지원자 = 가상 지원자 A·B·C + 구직자 화면에서 지원한 사람(파란 배경)

## 3. 채용 확정 → 근로계약서

1. 지원자 옆 **[채용 확정]**
   - 6개월 흐름을 시연하려면 먼저 **[기존 근로자 등록 (시연: 6개월분 급여 지급 완료)]** → 입사일이 6개월분 급여 지급일이 지난 시점으로 바뀜
2. 저장된 구직자 이름과 공고 조건으로 **고용노동부 표준근로계약서**가 채워짐 (왼쪽 칸에서 수정 가능)
3. 사업주 칸에는 회사 법인 인장(가상)이 자동으로 찍힘
4. 근로자 칸 **[✍ 서명 또는 인장]** → 직접 그리기 또는 인장 이미지(또는 '시연용 가상 인장 만들기')
   - 서명 없이 저장하면 구직자 화면 [내 서류함]에서 근로자가 [✍ 서명하기]로 서명할 수 있음
   - **서명 전에는 급여명세서를 발급할 수 없음** — 시연은 반드시 서명 → 저장 → 명세서 순서
5. [계약서 저장 · 근로계약 점검] → 규칙 점검 결과와 함께 담당자 신청 건이 만들어짐

## 4. 급여명세서 · 이체확인증

1. [💰 급여명세서 발급으로]
2. 달마다 [명세서 발급·전송] → 근로자 [내 서류함]에 명세서가 들어감
   - **매월 발급**: 지급일이 지난 달만 발급 가능, 아직 안 지난 달은 '발급 예정'
   - 직접 등록한 기업은 이음24 등록월 전 달이 '이음24 등록 전'(회사가 이미 발급한 명세서로 확인)
   - 월 중간 입사·계약 종료 달은 **일할 계산** (명세서에 '일할 계산: 월급 × 근무일/역일' 표시)
   - 계약서를 고쳐 다시 저장하면, 맞지 않게 된 명세서는 지우지 않고 **정정(취소)** 이력으로 남음
3. **이체확인증 첨부**: [예시 선택]에서 사례를 고르면 가상 은행 양식 이미지가 첨부됨 → [AI 판독 · 대조]
   - 정상 / 금액 다름 / 이체자 다름(대표 개인 계좌) / 받는 분 다름 — 비교표에서 어디가 다른지 확인
   - 직접 만든 이미지는 [내 파일 첨부] (AI 키가 있어야 판독)
4. 한 번에 보려면 [지급일 지난 달 명세서 발급 + 예시 이체확인증 대조 (시연)] (3장의 [기존 근로자 등록]을 한 경우 6개월분)

## 5. 담당자

1. 상단 [담당자] → 맨 위 '이음24 채용 확정 건'
2. [📄 근로계약서] [💰 급여명세서·이체 확인]으로 서류를 다시 요청하지 않고 바로 열람
3. [보완 요청] 또는 [검토 완료] → 처리 결과 저장

## 처음부터 다시

[기업] 기업 목록 아래 **[시연 데이터 초기화]**를 두 번 누르면 이 브라우저에 저장된 시연 데이터가 모두 지워집니다.
[저장 데이터 내보내기(JSON)]로 지우기 전에 파일로 받아 둘 수 있습니다.
