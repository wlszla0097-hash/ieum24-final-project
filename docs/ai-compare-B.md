# AI 비교 기록 — 팀원 B (모델: Claude Sonnet 4.6)

- 테스트일: 2026-10-16
- 게이트웨이: `ANTHROPIC_BASE_URL`(교육용 중계 서버, copa.codyssey.kr)
- 방법: 로컬 서버(`python dev_server.py`)의 `/api/seeker`(이력 정리·공고 추천)와 `action=portfolio`(포트폴리오)를 API로 호출해 측정
- 대상: 구직자 2명(`P-B01` 서지우, `P-B02` 백가람) × 추천 공고 상위 5건

- 두 명 모두 추천에서 제외된 공고 동일: 임금체불 2건, 고액·상습 체납 1건, 최저임금 미달 2건 (→ `excluded` 집계로 확인)

## 2. 공고마다 결과가 달라지는지

포트폴리오 초안은 현재 **구직자당 1회** 생성되고, **공고별 맞춤은 추천 이유(`reason`)와 지원 전 준비(`prep`)로만** 반영됩니다.

- **P-B01 서지우** — 같은 구직자여도 공고별 `reason`/`prep`이 다름:
  - `다온물류(경기)` → "요구 기술인 엑셀과 사무 역량을 … 물품 관리 경험이 입출고·재고 관리와 연결"
  - `바다로지스(부산)` → "엑셀·사무 훈련과 물품 관리 경험이 핵심 기술과 일치 … 통근/거주 이전 검토"
  - 배지도 공고별로 다름: 수도권 정규직 = 배지 표시(국취 최초취업), 비수도권/제외업종 = 미표시
- **P-B02 백가람** — 희망 직무(디자인) 기준으로 맞춤:
  - `브릿지랩(UX, 계약직)` → Figma·사용자 조사 연결 + 포트폴리오 공유 링크 준비 안내
  - `다온물류센터(물류)` → "디자인 역량과 직접적 연관이 없어 우선순위 낮음" (과장 없이 솔직하게 판단)

→ **요구 메모 v2의 "공고별 맞춤 포트폴리오"는 아직 구현 전**임. 현재는 `reason`·`prep`이 공고별로 갈리므로, 포트폴리오 본문까지 공고별로 만드는 연결이 필요함.

## 3. 할루시네이션 차단(guard) 관찰

- 이력 정리·추천(`run`): 두 명 모두 차단 문단 0 → 입력에 없는 숫자·지원금·연령 언급 없음.
- 포트폴리오(`portfolio`):
  - P-B01 **차단 2** — 활동 중 "진로·직업상담 … **취업활동계획** 수립"이 포트폴리오 금지어(프로그램명 비공개 규칙)에 걸려 해당 문단이 빠짐. 기업 화면에 참여 사업명이 노출되지 않도록 하는 의도대로 동작.
  - P-B02 차단 0 — 금지어에 해당하는 활동 없음.

## 4. 어색·오류 문장 관찰

- 응답 속도는 두 명 모두 약 23초(정리) / 8~9초(포트폴리오)로 유사, 시간 초과·재시도 없음.
- 뚜렷한 허위 수치·기간 생성은 없었음 (활동 `period`가 원문의 `YYYY-MM`과 일치).
- P-B02의 저-일치 공고(물류·개발)에서도 "연관성 낮음"으로 정직하게 이유를 달아 과대포장하지 않음 — 바람직.
- 최종 "어색한 문장" 판정은 사람이 확인 필요(원문 전체는 아래 JSON 참조).
