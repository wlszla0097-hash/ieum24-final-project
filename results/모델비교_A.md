# 모델 비교 기록 — 지수 (A)

- 사용 모델: Gemini · `gemini-flash-latest` (무료 키, 공식 API 직접 호출) — 연동 상태·내보내기 파일(`ai.model`) 기준
- 테스트일: 2026-10-17
- 대상: P-A01~P-A07 **7명 전원** 실행 (개발 서버가 한 번 꺼져 내보내기가 2개로 나뉘어 `export_A.json`으로 병합)
- 근거: `export_A.json`의 `ailog` 21건 (모델명·응답 시간·차단 수·결과 문장이 호출마다 기록됨)

## 1. 응답 시간 (성공한 호출만, 초)

| 구분 | 성공/호출 | 평균 | 중앙값 | 최소~최대 |
|---|---|---|---|---|
| 이력 정리·공고 추천 | 5/9 | 12.0 | 12.6 | 6.1 ~ 17.1 |
| 포트폴리오 초안 | 6/12 | 15.0 | 13.9 | 12.0 ~ 20.6 |

- 홍주님(Claude Sonnet 4.6, 교육용 게이트웨이) 기록: 이력 정리 약 23초, 포트폴리오 8~9초 → **이력 정리는 Gemini가 빠르고 포트폴리오는 느림**. 단, 홍주님은 2명 기준·게이트웨이 경유, 지수는 성공 5~6건·공식 API 직접 호출이라 단순 비교는 조심해야 함.

## 2. 실패·오류 기록 (무료 키 영향)

호출 21건 중 성공 11 · 입력 오류 2 · AI 쪽 오류 8.

| 유형 | 건수 | 내용 |
|---|---|---|
| 응답 지연(시간 초과) | 3 | 약 25초에서 끊김 — 강하윤·윤서연 이력 정리, 조민재 포트폴리오 |
| 사용량 한도 초과(429) | 3 | 강하윤 이력 정리 1, 포트폴리오 2 — 한도에 걸리면 0.3~0.4초 만에 즉시 실패 |
| 서비스 오류 503 | 1 | 강하윤 포트폴리오 (혼잡) |
| AI 응답 해석 실패 | 1 | 탁도영 이력 정리 (JSON 해석 못 함) |
| 입력 오류 400 | 2 | 임태오 — 청년도전 체크 상태에서 수료일이 없어 입력 단계에서 거절 (AI 문제 아님, 이후 재시도에서 정상) |

- AI가 실패하면 서버가 **규칙 기반 대체 문장**으로 보여 줌. 재시도하면 대부분 성공함.

| 구직자 | 기대 | 결과 | 비고 |
|---|---|---|---|
| P-A01 강하윤 | 대상 | **미확인** | 이력 정리 AI가 2번 실패(시간 초과·한도). 추천 목록에 제외 업종 1건(드림댄스홀)뿐. **합성 공고에 마케팅 직무가 0건**이라 맞는 공고가 안 나옴 |
| P-A02 조민재 | 대상 | ✅ true | 세진정밀·세움정밀 품질관리 공고 |

| P-A04 임태오 | 비대상 | ✅ 전부 false | 미수료 |

| P-A07 탁도영 | 대상 | ✅ true | 다온물류·다온물류센터(수도권 정규직). 군필 연령 연동 정상, 비수도권(바다로지스)은 false |

## 4. 차단 문단 수

- 성공한 호출 11건 모두 **차단 0건** (`guard_blocked=0`).
- 하지만 원문과 대조하면 5절처럼 **원문에 없는 설명이 남아 있음** → 차단 수가 0이어도 사람이 읽고 고쳐야 함.
