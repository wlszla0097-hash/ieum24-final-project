# 테스트 결과 올리는 곳

각자 컴퓨터에서 돌린 테스트 결과(구직자·포트폴리오·지원 기록·AI 호출 기록)는 GitHub에 자동으로 올라가지 않습니다.
아래 두 파일을 이 폴더에 넣어 **구직자 데이터와 같은 PR**로 올려 주세요.

| 담당 | 내보내기 파일 | 비교 기록 |
|---|---|---|
| 팀원 A | `results/export_A.json` | `results/모델비교_A.md` |
| 팀원 B | `results/export_B.json` | `results/모델비교_B.md` |

## 1. 내보내기 (개발 서버를 끄기 전에!)

개발 서버(`python3 dev_server.py`)는 테스트 결과를 **메모리**에만 저장합니다. 서버를 끄면 사라집니다.

1. 구직자 화면 → **📥 내 서류함** → **[📤 테스트 결과 내보내기(JSON)]** (기업 화면의 [저장 데이터 내보내기(JSON)]도 같은 파일)
2. 다운로드 폴더에 `ieum24-test-<모델이름>-<날짜>.json` 이 생김
3. 이 폴더로 옮기고 이름을 `export_A.json`(팀원 B `export_B.json`)으로 바꾸기

파일에 들어가는 것: 구직자(이력·역량 문장·포트폴리오), 지원 기록, **AI 테스트 기록**(호출마다 모델 이름·응답 시간·차단 수·결과 문장·추천 공고), 사용한 AI 모델.
API 키 값은 들어가지 않습니다.

## 팀장: 합친 뒤 한 화면에서 보기

1. PR을 합치고 `git pull`(또는 GitHub에서 `results/` 파일 다운로드)
2. 기업 화면 아래 **[결과 불러오기(JSON)]** (또는 구직자 [📥 내 서류함]의 [📥 결과 불러오기]) → `export_A.json`, `export_B.json` 함께 선택
3. 두 팀원의 구직자·지원·AI 기록이 이 브라우저에 합쳐짐 → 기업 화면에서 지원자 확인·채용 확정으로 이어서 시연
   - 같은 항목은 나중 파일 내용으로 덮어써서, 같은 파일을 다시 불러와도 늘어나지 않음
   - 항목마다 `imported_from`(파일 이름)이 남아 누구 결과인지 구분됨
   - 브라우저 저장이라 시연할 노트북·브라우저에서 불러와 두기

## 2. 모델 비교 기록 (`모델비교_A.md`)

```
- 사용 모델: (연동 상태에 보이는 이름)
- 같은 구직자 2명 × 같은 공고 2건
  - 포트폴리오가 공고별로 달라졌는지
  - 차단된 문단·문장 수
  - 응답 속도 (내보내기 파일의 ms 값 참고)
  - 어색하거나 틀린 문장 (원문과 다른 내용)
- 정상 사례는 '지원제도 활용 가능' 표시, 걸러져야 할 사례는 미표시인지
```

화면 캡처는 PR 설명에 첨부해 주세요. 캡처에 API 키가 보이지 않게 주의!
